01 · Media

फोटो या वीडियो

स्थानीय फोटो या वीडियो चुनें। फ़ाइल ब्राउज़र में प्रोसेस की जाएगी; upload के लिए किसी external service की आवश्यकता नहीं है।

JPG, PNG, WebP जैसी फोटो तथा browser-supported video फ़ाइलें चुनें। बड़ी फ़ाइलों के लिए processing समय डिवाइस और browser पर निर्भर करेगा।

चयनित फ़ाइल: कोई फ़ाइल चयनित नहीं

मीडिया विवरण चयन के बाद यहाँ दिखाई देगा।

अभी कोई मीडिया चयनित नहीं है

ऊपर से फोटो या वीडियो चुनने पर उसका preview यहाँ दिखाई देगा।

9:16 canvas में मूल aspect ratio को कैसे प्रस्तुत करना है, यह यहाँ नियंत्रित किया जाता है।

02 · Preview

9:16 Vertical Preview

अंतिम composition का canvas preview। logical rendering size 1080 × 1920 के लिए तैयार है और CSS के अनुसार responsive रूप से प्रदर्शित हो सकता है।

9:16 canvas preview इस browser में उपलब्ध नहीं है।

यदि canvas preview उपलब्ध न हो, तो नीचे के status क्षेत्र में rendering स्थिति और त्रुटि की जानकारी दी जाएगी।

Preview तैयार करने के लिए मीडिया चुनें

मीडिया, सुविचार और टिकर जोड़ने के बाद composition यहाँ दिखाई देगी।

04 · Color Text

मल्टी-कलर टेक्स्ट

अलग-अलग शब्दों या text segments के लिए अलग रंग निर्धारित करने हेतु extensible configuration।

मल्टी-कलर मोड सक्रिय करने के बाद text segments के रंग यहाँ JavaScript के माध्यम से प्रबंधित किए जाएँगे।

रंग निर्धारण शब्द, segment या line-based rendering के लिए extensible रखा गया है। वास्तविक segment controls चुने गए text के आधार पर module द्वारा बनाए जाएँगे।

05 · Voice

ब्राउज़र Voice / TTS

Text को browser की Speech Synthesis capability के माध्यम से पढ़ने के लिए उपयोग करें।

लयबद्ध और वैदिक modes browser speech engine की उपलब्ध prosody capabilities का उपयोग करने का प्रयास करेंगे; किसी विशिष्ट गायन या शास्त्रीय उच्चारण की गारंटी नहीं है।

Voice list

07 · Export

Recording और Export

Canvas composition को browser-supported media recording के माध्यम से रिकॉर्ड करें और local file के रूप में डाउनलोड करें।

Recording time 00:00

WebM सामान्यतः browser MediaRecorder workflows में व्यापक रूप से उपलब्ध रहता है। MP4 support browser/device के अनुसार जाँचा जाएगा।

Export compatibility browser की MediaRecorder और MIME type support पर निर्भर करेगी। उपलब्ध format को runtime पर जाँचना आवश्यक है।

Recording के लिए preview और browser capability तैयार होना आवश्यक है।

रिकॉर्डिंग बनने के बाद फ़ाइल format, size और अन्य उपलब्ध विवरण यहाँ दिखेंगे।

Privacy और compatibility

यह interface browser-based processing architecture के लिए बनाया गया है। External API, payment gateway या अनिवार्य backend dependency इस HTML में शामिल नहीं है।

वास्तविक processing और browser capabilities `script.js` तथा `modules/` द्वारा नियंत्रित होंगी।

Capability checks

  • Canvas जाँच लंबित
  • Speech Synthesis जाँच लंबित
  • MediaRecorder जाँच लंबित
  • MP4 जाँच लंबित
  • PWA जाँच लंबित

Swar Srijan Studio

Browser-based, privacy-friendly studio for creating 9:16 short-form video compositions without mandatory external APIs.
