Swar Srijan Studio Version 0.1.0

Browser-based और privacy-friendly studio। मीडिया और टेक्स्ट processing स्थानीय browser environment में की जाती है। किसी external API या अनिवार्य server की आवश्यकता नहीं है।

बेहतर अनुभव के लिए आधुनिक, Canvas और MediaRecorder समर्थित browser का उपयोग करें। Voice, recording और MP4 support device तथा browser के अनुसार बदल सकता है।
